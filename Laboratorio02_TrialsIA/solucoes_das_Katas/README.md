# 📁 Soluções das Katas

Diretório destinado ao armazenamento de todas as soluções desenvolvidas durante os *trials* do experimento (Sprint 02), cobrindo tanto as resoluções manuais quanto as assistidas por IA.

---

## 🏷️ Padrão de Nomenclatura

Para que o script de avaliação automática (`executar_bateria.py`) identifique e processe os arquivos corretamente, **todos os arquivos devem seguir rigorosamente a estrutura:**

```text
kata0[número]_[integrante]_[tratamento].py

Onde:
* **`[número]`**: Número respectivo da Kata respondida (ex: `1`, `2`, ..., `6`).
* **`[integrante]`**: Seu primeiro nome em letras minúsculas (ex: `vinicius`, `aulus`, `maria`).
* **`[tratamento]`**: Forma pela qual a Kata foi resolvida, podendo ser **exclusivamente**:
  * `"manual"` — Solução desenvolvida manualmente.
  * `"ia"` — Solução desenvolvida com auxílio de IA.
