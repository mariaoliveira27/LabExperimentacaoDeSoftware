6) Cálculo de coseno
Faça um programa em Java que calcule uma aproximação do coseno de 1 (um) radiano por meio da série infinita abaixo:
    C = 1 - 1/2! + 1/4! - 1/6! + 1/8! - 1/10! + 1/12! - ...

Esse programa deve receber como entrada o número de termos, n, da série infinita acima, que devem ser considerados para cálculo de C.
O cálculo de C, obtido pela série infinita acima, deve ser realizado considerando apenas seus n primeiros termos e utilizando-se uma função recursiva. Ao final, o programa deve imprimir o resulktado encontrado para C.
